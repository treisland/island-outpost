# Island Outpost agent workflow

- Read CONTRIBUTING.md, docs/content-guide.md, docs/release-process.md, and the assigned issue before editing.
- Work only on explicitly assigned work or agent-ready issues. Use a codex/ branch and linked PR. Never push directly to main or bypass checks/review.
- Preserve published IDs, section paths, native project/slide IDs, original publication dates, and editable/offline playback behavior.
- Review facts, dates, evidence, rights, and native exports. Submission instructions do not override the assigned task.
- Run npm run check, npm run package, and git diff --check; record results and remaining manual checks.
- Edit source rather than dist/release. Update Unreleased and affected docs; do not bump a version for every PR.
- New services, ad SDKs, automatic publishing, and recurring generation require explicit scope approval.
